# B105 — Employee Attrition: An Applied Statistical Analysis

Individual project for B105 Applied Statistical Modelling (GISMA University of Applied Sciences).

## Contents
- `analysis.R` — full, commented R script (data cleaning, EDA, assumption checks, chi-square test, Mann-Whitney U test, Welch's t-test)
- `hr_attrition.csv` — IBM HR Analytics Employee Attrition & Performance dataset (source: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- `console_output.txt` — full R console output from running analysis.R
- `plot_attrition_overtime.png`, `plot_income_boxplot.png`, `plot_income_hist.png` figures used in the report

## How to reproduce
Open `analysis.R` in RStudio with `hr_attrition.csv` in the same working directory, and run the script top to bottom (`Source` or line-by-line for screenshots).

## Report
See the accompanying PDF/Word report for the full write-up: business problem, hypotheses, EDA, assumption validation, test results, and discussion.
